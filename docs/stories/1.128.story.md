- [x] AC1: O layout raiz carrega Archivo (eixo de largura) como `--font-display`, com `display: swap`, e o IBM Plex Sans ganha os pesos 600 e 700 para números de placar.

- [x] AC4: A súmula, o telão, o painel, o login (Anton) e o ranking não mudam.
- [x] AC5: Sem rolagem horizontal de 320 px a 1440 px nas telas tocadas.
