# Story 1.3 - Evolução Fitness Racing / HYROX

## Status

Ready for Review

## Context

Implementar a experiência específica de eventos Fitness Racing, HYROX e HYROX Inspired dentro do WODArena, sem alterar regras de Functional Fitness. Eventos Fitness Racing devem nascer com estrutura pré-configurada de mercado e permanecer totalmente editáveis pelo organizador.

## Acceptance Criteria

- [x] AC1: Ao criar evento `fitness_racing`, o sistema gera categorias padrão Individual, Duplas e Revezamento.
- [x] AC2: Categorias exibem nome, formato, status, participantes, valor e ações de editar, excluir e duplicar.
- [x] AC3: Categorias Fitness Racing suportam faixas etárias padrão 16-24 até 60+ quando habilitadas.
- [x] AC4: Cada categoria Fitness Racing recebe percurso padrão Run/Ski/Sled/Burpee/Row/Farmers/Sandbag/Wall Balls.
- [x] AC5: Editor de percurso usa timeline vertical com editar, excluir, reordenar e inserir etapa abaixo.
- [x] AC6: Estações possuem nome, tipo, distância, repetições e pesos masculino/feminino editáveis.
- [x] AC7: Biblioteca pronta de estações permite preencher novas etapas rapidamente.
- [x] AC8: Cadastro público Fitness Racing coleta dados obrigatórios do atleta e normaliza Instagram sem `@`; foto, telefone e e-mail são opcionais.
- [x] AC9: Leaderboard Fitness Racing usa tempo oficial e diferença para o líder, sem pontuação por WOD.
- [x] AC10: Perfil de atleta/equipe exibe dados pessoais/equipe, tempo oficial e análise de performance quando houver splits.
- [x] AC11: Quality gates disponíveis passam sem erros.

## Scope

### In

- Presets Fitness Racing/HYROX.
- Geração automática no AppContext.
- Ajustes no admin para categorias, percurso e biblioteca de estações.
- Ajustes no formulário público de inscrição.
- Ajustes no leaderboard/perfil Fitness Racing.

### Out

- Mudanças de regra no Functional Fitness.
- Gateway de pagamento real.
- Exportações avançadas.
- Upload real de imagem.
