# Story 1.8 - Redesign Premium da Tela de Login

## Status

Completed

## Context

Redesenhar a tela de login da rota `/admin` para transmitir a entrada oficial de uma plataforma esportiva premium de competições, mantendo a identidade visual WOD Arena inspirada no sistema Binance documentado em `desinger-novo.md`.

O login continua atendendo atletas, gestores e administradores pela mesma rota, sem alterar o fluxo real de autenticação por role.

## Acceptance Criteria

- [x] AC1: A rota `/admin` mantém o login único para atleta e organizador.
- [x] AC2: A tela usa header premium com altura controlada e identidade WOD Arena.
- [x] AC3: O layout desktop usa divisão institucional/autenticação.
- [x] AC4: A área institucional usa asset esportivo local com overlay escuro.
- [x] AC5: O hero comunica `CONECTE. COMPITA. CONQUISTE.`.
- [x] AC6: A tela exibe estatísticas e benefícios esportivos.
- [x] AC7: O card de login usa fundo escuro, borda fina e radius de 12px.
- [x] AC8: O seletor `ATLETA / ORGANIZADOR` altera apenas o contexto visual, sem alterar a API de login.
- [x] AC9: O CTA principal usa amarelo WOD Arena e texto `Entrar na Arena`.
- [x] AC10: O CTA secundário `Criar conta gratuita` aponta para o fluxo real de eventos.
- [x] AC11: A tela é responsiva, com imagem como background no mobile e estatísticas em grid.
- [x] AC12: Quality gates executados com sucesso.

## Scope

### In

- Redesign visual do estado não autenticado de `/admin`.
- Reuso do `Navbar` atual.
- Uso de asset esportivo local já existente.
- Seletor visual de perfil.
- Mensagem de recuperação de senha sem criar fluxo falso.
- CTA para eventos como caminho real de criação de conta de atleta.

### Out

- Nova API de recuperação de senha.
- Cadastro autônomo fora do fluxo de inscrição.
- Alteração do contrato de login.
- Alteração de permissões por role.
