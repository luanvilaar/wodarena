## User Story

**Como** gestor,
**quero** fixar uma tela, acertar o relógio e encerrar uma bateria com súmula pendente,
**para** corrigir o telão quando a quadra não segue o roteiro.

## Acceptance Criteria

- [x] AC1: `set_mode`: automático, fixar bateria (do cronograma), fixar o geral de uma categoria do evento (outra categoria: 404) ou espera.
- [x] AC2: `mark_heat`: `start` grava a largada (o relógio do telão passa a contar dela), `finish` força o intervalo, `reopen` desfaz o encerramento. Outra ação: 400.
- [x] AC3: Aba "Telão": o que está no ar agora, a bateria detectada com o estado de cada raia, os botões Largada e Encerrar, e Reabrir para baterias encerradas pela mesa. Atualiza a cada 5 s.
- [x] AC4: Mesmas regras de acesso da Story 1.53; limite de 60 ações por minuto por pessoa.
- [x] AC5: Testes e gate `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
