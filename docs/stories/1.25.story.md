# Story 1.25 - Cancelamento de Inscricao com Reembolso Manual

## Status

Ready for Review

## Context

Gestores de evento precisam cancelar inscricoes quando o atleta solicita cancelamento. A estrategia financeira aprovada evita estorno automatico pelo Mercado Pago: a devolucao sera controlada manualmente pelo gestor, registrando o valor que efetivamente sera devolvido e deixando claro que, em pagamentos por credito, taxas de servico da WODArena e taxas do Mercado Pago nao sao reembolsadas nas devolucoes sujeitas a politica do organizador.

## User Story

**Como** gestor de evento,
**quero** cancelar uma inscricao aprovada e controlar o reembolso manual,
**para que** eu consiga atender solicitacoes de cancelamento sem acionar estorno automatico no gateway.

## Acceptance Criteria

- [x] AC1: O modelo de inscricao persiste motivo/data/responsavel do cancelamento e status/dados do reembolso manual.
- [x] AC2: Existe operacao CLI para cancelar inscricao e marcar reembolso manual como concluido.
- [x] AC3: A API administrativa permite que apenas owner ou gestor dono do evento cancele inscricoes do evento.
- [x] AC4: Cancelar uma inscricao altera `payment_status` para `payment_cancelled`, preserva historico financeiro e remove a inscricao de listagens ativas/ranking via sincronizacao existente.
- [x] AC5: O painel do gestor exibe controle de cancelamento na inscricao expandida e mostra o status do reembolso manual.
- [x] AC6: O painel permite marcar o reembolso manual como concluido, registrando valor, metodo, observacao, data e responsavel.
- [x] AC7: Os termos informam que, nos reembolsos sujeitos a politica do organizador, pagamentos no credito nao devolvem taxas de servico WODArena e Mercado Pago.
- [x] AC8: Testes cobrem migration, CLI, API, contexto, painel e comunicacao da politica.

## Scope

### In

- Migration Supabase idempotente para campos de cancelamento e reembolso em `registrations`.
- CLI para cancelamento e confirmacao manual de reembolso.
- Acao administrativa server-side com autorizacao por evento.
- Mapeamento dos novos campos no bootstrap privado e no `AppContext`.
- Controle no painel de inscricoes do gestor.
- Texto de politica em `/termos`.
- Teste estatico focado no fluxo aprovado.

### Out

- Estorno automatico via Mercado Pago.
- Integracao com API de refunds do Mercado Pago.
- Fluxo publico para atleta solicitar cancelamento autonomamente.
- Calculo automatico de taxas do Mercado Pago.
- Exclusao fisica da inscricao, atleta, pagamento ou historico.

## Dev Notes

- Usar `payment_cancelled` como status operacional do cancelamento.
- Manter reembolso como processo manual: nenhuma chamada de refund/estorno ao Mercado Pago.
- Valor de reembolso deve ser informado pelo gestor, pois pode representar o valor liquido recebido.
- Pagamentos por credito devem comunicar que taxas WODArena e Mercado Pago nao sao devolvidas fora das hipoteses obrigatorias de reembolso integral.
- Leaderboard ja remove entradas quando `payment_status` deixa de ser `payment_approved`.
