# Story 1.11 - Tamanho de Camisa e Exportação para Fornecedor

## Status

Ready for Review

## Context

O formulário público de inscrição coletava foto opcional do atleta. Para operação de entrega de kits, o gestor precisa coletar o tamanho da camisa e exportar uma planilha com os dados dos atletas para enviar ao fornecedor.

## Acceptance Criteria

- [x] AC1: O formulário de inscrição substitui a foto opcional por tamanho de camisa.
- [x] AC2: O tamanho de camisa é coletado por participante, incluindo integrantes de equipes.
- [x] AC3: O tamanho de camisa é persistido em `athletes.shirt_size`.
- [x] AC4: Dados de integrantes de equipe preservam `shirtSize` em `teamMembers`.
- [x] AC5: A aba de inscrições do gestor exibe tamanho de camisa.
- [x] AC6: A aba de inscrições exporta uma planilha `.xls` com dados de atletas e tamanhos para fornecedor.

## Scope

### In

- Campo de tamanho de camisa no formulário público e bilheteria.
- Persistência do tamanho em atletas.
- Exportação Excel-compatible para fornecedor na aba de inscrições.

### Out

- Controle de estoque de camisas.
- Upload ou armazenamento de foto de atleta.
- Integração direta com fornecedor.
