# Story 1.4 - Alteração de Senha do Gestor

## Status

Ready for Review

## Context

Permitir que o gestor altere sua própria senha de acesso ao painel de controle do site a partir da nova aba "Segurança". Isso atende ao fluxo onde o proprietário (owner) define uma senha temporária ao criar um novo gestor, cabendo ao gestor redefinir sua senha para algo privado.

## Acceptance Criteria

- [x] AC1: Adicionar opção **"Segurança"** com ícone `Lock` no menu lateral do painel do gestor (`/admin`).
- [x] AC2: Renderizar um formulário de alteração de senha de visual premium sob a aba Segurança.
- [x] AC3: Exigir o preenchimento de: Senha Atual, Nova Senha e Confirmação da Nova Senha.
- [x] AC4: Implementar validações no formulário:
  - Senha atual deve ser válida (igual à cadastrada).
  - Nova senha deve ter no mínimo 6 caracteres.
  - Confirmação da nova senha deve ser idêntica à nova senha.
- [x] AC5: Atualizar a senha de forma persistente no Supabase (tabela `users`) e nos estados globais/locais (`users`, `currentUser` e local storage).
- [x] AC6: Exibir notificações visuais em caso de sucesso ou erro durante o processo de alteração.

## Scope

### In

- Adição do método `changePassword` no `AppContext`.
- Atualização na tabela `users` do Supabase via RPC ou update convencional.
- Interface visual na página `/admin` do painel com aba "Segurança".
- Feedback visual para o usuário.

### Out

- Recuperação de senha por e-mail (esqueci minha senha) nesta story.
- Autenticação por múltiplos fatores (MFA).
